Alpha Rarefaction Help

The Rarefaction Curves plot on top shows the chosen alpha diversity metric (from the dropdown menu) at each depth for every sample as a curve. Change it to see a different metric. Change the grouping of the data with the 'group by' dropdown menu.

The optimal rarefaction depth is depicted as the vertical red line. It is the knee point that was calculated using the {{ algorithm }} algorithm.

The lower plot shows the number of samples which have enough reads to be included at that depth, and were used to calculate the curve in the upper plot. This is important to consider when choosing a rarefaction depth, as a very high depth may lead to very few samples being included in the analysis.

Select / Deselect all samples with the checkbox above the legend. You can also click on individual samples in the legend to select/deselect them. Only the currently selected samples will be shown in the plots.

Click the '⬇ Download CSV' button to download a CSV file with the data used to create the plots. This includes the alpha diversity values for each sample at each depth, as well as their metadata.
