Beta Rarefaction Help

This visualization shows the rarefaction curve for the beta diversity metric chosen in the dropdown menu. The Rarefaction Curve plot on top shows the average differences between the distance matrices at the different read depths. Each distance matrix was compared to its previous one, in the samples that overlap. The difference in the distance between each sample was calculated and the overall average taken and plotted. The curve shows how the average difference changes with increasing read depth.

The optimal rarefaction depth is depicted as the vertical red line. It is the knee point that was calculated using the {{ algorithm }} algorithm.
The lower plot shows the number of samples that had enough reads to be included at the respecive read depth.

Click the '⬇ Download CSV' button to download a CSV file with the points used to create the rarefaction curve. Click the '📦 Download Distance Matrices (.zip)' button to download a ZIP file containing the distance matrices for each metric at each rarefaction depth.
